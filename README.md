Repository ini berisi tugas praktikum Pemrograman Berbasis Web (Kelas A).

## Isi Repositori

- `biodata.php` - Program PHP sederhana untuk menampilkan biodata mahasiswa dan status kelulusan berdasarkan IPK.
- `kalkulator.php` - Program PHP kalkulator sederhana yang memproses operasi aritmatika dasar (`+`, `-`, `*`, `/`, `%`).

## Cara Menjalankan

1. Pastikan PHP sudah terinstal pada komputer Anda.
2. Jalankan PHP built-in server di dalam direktori project:
   ```bash
   php -S localhost:8000
   ```
3. Buka browser dan akses:
   - `http://localhost:8000/biodata.php`
   - `http://localhost:8000/kalkulator.php`
